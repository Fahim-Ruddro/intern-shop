# Intern Shop

Full-stack e-commerce storefront built with Next.js (App Router), TypeScript, Tailwind CSS, and Supabase.

## Completed Setup
- PostgreSQL schema & migrations (`categories`, `products`)
- Seeded 30 products across 6 categories
- Public `product-images` Supabase Storage bucket
- Generated TypeScript database types & data access layer (`lib/data/products.ts`)
- Dynamic Product Detail Page (`/products/[slug]`)
